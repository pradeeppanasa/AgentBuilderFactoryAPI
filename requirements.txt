# Guardrail Layer 1 (app/modules/guardrails/bert_classifier.py) — local ONNX
# Runtime inference, CLAUDE_Advanced_Config.md Section 3.5. Deliberately NOT
# `optimum`: every version of optimum (including its "onnxruntime" extra)
# lists `torch>=1.11` as a mandatory, non-optional dependency in its own
# package metadata — there is no way to install it without pulling PyTorch
# into the image, which the no-PyTorch-in-production requirement rules out.
# onnxruntime (pure C++ inference engine) + tokenizers (HF's standalone Rust
# tokenizer library) together load and run a pre-exported ONNX model with
# zero PyTorch/TensorFlow anywhere in the dependency tree. Both imports are
# lazy (deferred to first classifier.score() call, not module import). The
# model artifact itself (model.onnx + tokenizer.json + config.json) is never
# downloaded at runtime — it must be supplied via GUARDRAILS_BERT_MODEL_DIR,
# populated during image build or by customer-side artifact placement.
